# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-08-05

### Added
- Initial repository setup and engineering foundation.
- TypeScript strict configuration with path aliases (`@app`, `@core`, `@features`, `@shared`).
- Code quality tooling: ESLint, Prettier, Husky, lint-staged, Commitlint.
- Testing infrastructure: Jest and React Native Testing Library.
- Multi-environment setup (`development`, `staging`, `production`).
- GitHub Actions CI workflow for linting, type-checking, unit testing, and Android build verification.
- Complete Clean Architecture and feature-first folder structure.
- Core project documentation and community guidelines.
